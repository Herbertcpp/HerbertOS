# HerbertOS

## Reason
Small OS project I started recently as part of my learning journey throughout the world of low level development

## Aim
I want to see how computers work first hand with this little project. It is meant as a learning experience

## Development
Admittedly I have had / am having quite a hard time with this. I mainly use osdev wiki as reference, but as it is just a reference not tutorial this is quite a challenge. 

## Implementing goals
- Finishing PIC + IDT to get Interrupts working
- Filesystem Support
- System Calls
- Basic shell support
- Custom C library
- Threads
- Maybe more things, but this is the core for now

## Summary
I enjoy learning about this, even though it's quite a challenge. I'm focusing on implementing the core things and I will see what awaits me after :)
